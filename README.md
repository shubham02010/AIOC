# AIOC

An original, browser-first collection of carefully designed developer tools.

## Phase 1

- Premium responsive shell with dark/light themes
- Tool directory, category pages, command search, legal pages, sitemap, and robots rules
- Central tool metadata registry
- JSON Formatter with formatting, validation, minification, copy, download, reset, keyboard shortcut, and helpful errors

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Checks

```bash
pnpm typecheck
pnpm build
```
